# /backups

Scripts de referencia para respaldar una instalación (base de datos + archivos subidos), no backups
binarios reales. Los backups reales de cada colegio se guardan en
`deployment/CLIENTES/<Colegio>/backups/`, fuera de este repositorio de desarrollo o en almacenamiento
externo, nunca commiteados aquí.

Ver `docs/BACKUP.md` para la política completa (qué respaldar, cada cuánto, dónde guardarlo,
cómo restaurar).
