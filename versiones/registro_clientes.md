# Registro de versiones por cliente

Tabla de control: qué colegio tiene instalada qué versión del producto, y cuándo. Se actualiza cada
vez que se entrega una instalación nueva o se aplica una actualización a una ya existente. Pensada
para que el usuario (sin necesidad de abrir código) sepa de un vistazo el estado de cada cliente.

|---|---|---|---|---|
| _(sin instalaciones bajo el nuevo modelo todavía)_ | — | — | — | — |

Ver `/releases` para el contenido de cada versión.
