# /storage

Esta carpeta documenta dónde vive el almacenamiento persistente (archivos generados en runtime,
no código) de cada instalación real: PDFs de boletines generados, exportes de Excel, backups
temporales antes de subirse a `/backups`.

**No contiene archivos reales de ningún colegio.** Cada instalación en producción tiene su propio
storage físico en su propio servidor — esta carpeta es solo referencia de estructura para quien
instale un colegio nuevo.
