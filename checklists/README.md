# /checklists

Checklists operativos, pensados para que el usuario o un técnico externo los siga sin necesidad de
leer código:

- `CHECKLIST_DATOS_INSTITUCIONALES.md` + `.csv` — formulario de intake para un colegio nuevo (datos
  institucionales, dominio/hosting, base de datos, SMTP, usuario administrador, configuración
  académica).
- `CHECKLIST_IMPLEMENTACION.md` — validación completa antes de entregar una instalación nueva.
- `CHECKLIST_ACTUALIZACION.md` — procedimiento de 15 pasos para actualizar un colegio ya instalado
  a una versión nueva sin perder su configuración ni personalización.

Los tres ya están redactados con contenido real, listos para usarse.
