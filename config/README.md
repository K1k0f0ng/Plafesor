# /config

Plantillas y ejemplos de configuración del core del producto. **Nunca contiene secretos reales** —
ni contraseñas, ni claves de API, ni tokens de un colegio real. Eso vive únicamente en el `.env` de
cada instalación (en el servidor de cada colegio), nunca en este repositorio de desarrollo.

Aquí van archivos `.env.example` ampliados y el esquema documentado de cada variable de configuración
(qué significa, de dónde se obtiene, si es obligatoria u opcional). El detalle de cada variable se
documenta en `docs/CONFIGURACION.md`.
