# /install

Guía de instalación paso a paso para poner en marcha un colegio nuevo a partir de
`deployment/PLAYFESOR_TEMPLATE/`, pensada para que un técnico sin contexto previo del proyecto
pueda seguirla sin tener que preguntar nada.

El contenido detallado vive en `docs/INSTALACION.md` (Fase 4 del plan de rearquitectura). Esta
carpeta queda reservada para scripts de apoyo a la instalación manual, si se necesitan más adelante
(por ahora no hay automatización — el flujo de trabajo del proyecto es manual, sin CI/CD).
